# Model Picker Playwright Validator

Visual validation container for https://model-picker.relate-ai.site.

Checks:
- desktop/mobile rendering
- 213 catalog rows
- search/filter/sort
- model detail
- compare
- routing cases
- telemetry auth gating
- mobile overflow

Screenshots and result are written to the mounted `/app/screenshots` volume.

Recorded comparison video: screenshots/two-provider-comparison.webm
